## What it is
As skills disponíveis para o [[claude-app]] (aparecem para o Claude Code como `anthropic-skills:*`). A maioria são as versões do app das [[skills]] locais; algumas só existem lá.

## What it does
Só no app, entre outras: docs, docx, pdf, pptx, xlsx e google-workspace (documentos e arquivos Google), import-memory, morning (um resumo da manhã), setup-writing-style, skill-creator e deutsch-gespraech-memory ([[deutsch-gespraech]]). A gui-code-protocol ainda aparece lá, mas pertence ao fluxo aposentado ([[retired-workflow-pipeline]]).

## How it does it
Gerenciadas no app do Claude; cada lado mantém sua versão. O Claude Code não vê mudanças no conteúdo delas, então esta página tem uma data de revisão em vez de fontes.

## Where it sits in the pipeline
Fora do notebook.

## Who receives its output
O [[claude-app]].
