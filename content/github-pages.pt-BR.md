## What it is
O [GitHub Pages](https://pages.github.com/) é a hospedagem gratuita do GitHub para sites "estáticos", isto é, sites feitos só de arquivos prontos (páginas web em HTML, HyperText Markup Language; scripts; imagens), sem nenhum programa rodando no servidor. Ele serve o [[quizweb]] em `https://yujideluca.github.io/german-quiz-web/`, a partir do branch `main` (a linha principal do histórico do projeto).

## What it does
Publica um push para `main` em cerca de um minuto.

## How it does it
Só arquivos estáticos são servidos; não há código de servidor.

## Where it sits in the pipeline
O fim do pipeline do [[quizweb]].

## Who receives its output
Qualquer navegador, principalmente o iPhone do Giovanni.
