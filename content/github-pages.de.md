## What it is
Das kostenlose statische Hosting von GitHub. Es liefert [[quizweb]] unter `https://yujideluca.github.io/german-quiz-web/` aus dem Branch `main` aus.

## What it does
Veröffentlicht einen Push auf `main` innerhalb von etwa einer Minute.

## How it does it
Nur statische Dateien; kein Servercode.

## Where it sits in the pipeline
Das Ende der Pipeline von [[quizweb]].

## Who receives its output
Jeder Browser, vor allem Giovannis iPhone.
